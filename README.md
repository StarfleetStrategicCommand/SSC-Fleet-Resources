# SSC Fleet Resources

Official public resource library for **Starfleet Strategic Command**, an independent Star Trek Online fleet community.

This repository brings SSC guides, checklists, event information, and community resources into one organized location. Resources will grow as new material is reviewed and published.

## Repository Structure

- `guides/` contains player and fleet guides.
- `checklists/` contains quick-reference resources.
- `events/` contains reusable event information.
- `assets/` contains approved public SSC media files when available.

## About Starfleet Strategic Command

Starfleet Strategic Command focuses on teamwork, accessible guidance, fleet participation, and a welcoming Star Trek Online community.
